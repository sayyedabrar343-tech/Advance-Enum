------------------------------------------------------------
[01] CEMT INQUIRE SYSTEM
------------------------------------------------------------
Look For:
  - CONFDATA = SHOW
  - SEC = NO
  - XCMD = YES + CMDSEC = NO
  - DUMPING = SYSD
  - TRACESIZE > 0

Vulnerability If Found:
  - CONFDATA=SHOW -> Passwords/tokens exposed in dumps and traces
  - SEC=NO -> Security completely disabled; no authentication
  - XCMD=YES + CMDSEC=NO -> Command security disabled
  - DUMPING=SYSD -> Sensitive data being dumped
  - TRACESIZE > 0 with CONFDATA=SHOW -> Data leak via trace

Why Valid Even With Admin Rights:
  - Security is off for EVERYONE, not just admin
  - Any user can execute transactions without auth
  - Audit trail is absent (compliance violation)
  - Insider threat: Admin can misuse without logs

Risk: CRITICAL
