  3. 10.5p1 MEIN FIX KI GAYI VULNERABILITIES
================================================================

----------------------------------------------------------------
Issue                    : Agent Locking Bypass
Fixed Version            : 10.5p1
CVE                      : None assigned (security fix)
Description              : Agent locking ke dauran session binding 
                           requests galat handle ho rahe the. Remote 
                           operations (PKCS#11 tokens add karna) 
                           allowed ho rahe the, jabki sirf local 
                           operations ki permission honi chahiye thi.
----------------------------------------------------------------

----------------------------------------------------------------
Issue                    : Client Use-After-Free
Fixed Version            : 10.5p1
CVE                      : None assigned (security fix)
Description              : Multiplexed connections mein remote 
                           forwarding add karne par use-after-free 
                           vulnerability.
----------------------------------------------------------------

----------------------------------------------------------------
Issue                    : authorized_keys 'restrict' Bypass
Fixed Version            : 10.5p1
CVE                      : None assigned (security fix)
Description              : authorized_keys mein 'restrict' keyword 
                           tunnel forwarding par apply nahi ho raha 
                           tha.

Status                   : DISPUTED
